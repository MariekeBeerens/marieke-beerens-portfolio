# Planning & Processen rapportage

## Situatie

De afdeling Planning & Processen werkte met meerdere losse werkdocumenten voor managementrapportages.

Er was behoefte aan één centrale rapportage.

## Mijn rol

Verantwoordelijk voor het volledige traject.

## Werkzaamheden

- Requirements ophalen
- Stakeholdergesprekken
- Ontwikkelen rapportage
- Inrichten werkwijze voor hulpvragen
- Opleveren en presenteren

## Gebruikte tooling

- Power BI
- Power Query
- Azure DevOps

## Resultaat

Een centrale managementrapportage die periodiek wordt gebruikt binnen de afdeling en wordt gepresenteerd aan management.

## Opgestelde werkwijze

- Haalbaarheidsassessment
- Intake & planning
- Refinement
- Review
- Handover
- Einddemo
- Retrospective
