#TOPdesk SaaS Migratie

## Situatie

De organisatie migreerde van een on-premise TOPdesk omgeving naar een SaaS omgeving.

Hierdoor veranderden datastructuren, veldnamen en beschikbare informatie.

## Mijn rol

Verantwoordelijk voor het aanpassen van bestaande rapportages aan de niewue datastructuur.

## Werkzaamheden

- Analyse nieuwe datastructuur
- Aanpassen Power Query logica
- Testen van rapportages
- Validatie van resultaten
- Optimaliseren prestaties

## Gebruikte tooling

- Power BI
- Power Query
- Azure DevOps

## Resultaat
Succesvolle overgang van bestaande managementrapportages naar de nieuwe SaaS omgeving met behoud van rapportagefunctionaliteit.
